# Теплогранд — продажи

Рабочий стол отдела продаж ООО «ТеплоГранд»: лиды, компании, контакты, воронка, коммерческие предложения и задачи. Это отдельный срез для согласования. На сайт каталога он не выкладывается.

Три учебные учётки — Марина Соколова, Артём Белов и Кира Лебедева. Переключение в колонке «Вы за столом», пароль не нужен. У каждого свои лиды и заметки после звонка. На одной странице «Лиды» пять групп: новые, недозвон, перенос сроков, обратная связь и теплые. Сверху список «Кому звонить сегодня» — только лиды текущего продавца: новые, недозвон и перенос сроков, если момент перезвона сегодня или уже прошёл. В «Перенос сроков» продавец ставит дату и время; перенос в эту группу спрашивает срок. Поиск идёт сразу по всем группам: имя, телефон, компания. Карточка лида открывается поверх списка: поля сохраняются, к номеру можно дописать, чей он, плюс добавляет сайт и ссылку на Яндекс Карты, «+ Задача» ставит задачу на этот лид. В карточке можно записать несколько звонков подряд: дата, время, итог той же группой, что на доске, и заметка. История и заметка видны только этому продавцу и не попадают в карточку компании. Сделки, КП и каталог общие.

Категории, скидки и расчёт цены повторяют каталог продавца: Д1 (партнёр / МОЦ), Д2 (крупный опт), Д3 (опт), РРЦ и скидка частникам 5% или 10%. Калькулятор, как и в каталоге, подставляет Д1–Д3 для LD Pride и для Arderia / «ТГУ-НОРД / Arderia». Остальные группы ценовой политики от 20.01.2026 в списке видны, но в ставку сами не попадают — для них в КП выбирается колонка прайса.

Розничные цены четырёх термоблоков ТГУ-НОРД-С24 взяты с открытой карточки b2b.rusklimat.com (коды НС-1761220, НС-1761219, НС-1761222, НС-1761221). Остальные суммы — учебные и помечены «демо». Клиенты в поставке тоже учебные.

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на [http://127.0.0.1:47231](http://127.0.0.1:47231).

Данные живут в браузере. Кнопка «Вернуть демо-данные» в боковой колонке восстанавливает учебный набор.
